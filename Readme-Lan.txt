 Enhancing LAN Security by Mitigating Credential Threats via HTTP Packet Analysis

 Paper Info
- Authors: Altaf Hussain, Aamir Hussain, Salman Qadri, Abdul Razzaq, Hira Nazir, Muhammad Sami Ullah
- Published: 2024
- Institution: Muhammad Nawaz Sharif University of Agriculture, Multan, Pakistan
Abstract
[Paste your abstract]

 Vulnerability Demonstrated
- HTTP transmits credentials in plaintext
- Wireshark captures POST packets containing username/password
- Attackers on same LAN can sniff credentials

Tools Used
- Wireshark
- Nmap
- HTTP protocol analysis

Mitigation Implemented
- HTTPS instead of HTTP
- Multi-factor authentication
- Firewall rules
- Network segmentation
- Regular monitoring

Skills Demonstrated
- Vulnerability Assessment
- Network Traffic Analysis
- Packet Capture (PCAP)
- Threat Mitigation
- Security Monitoring
